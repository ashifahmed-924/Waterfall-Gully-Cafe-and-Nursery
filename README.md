# Waterfall Gully Cafe and Nursery

Next.js site for Waterfall Gully Cafe & Nursery (Rosebud, VIC).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint
